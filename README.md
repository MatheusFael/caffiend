# ☕ Caffiend

Caffiend é o app definitivo para quem ama café e quer acompanhar de perto seu consumo, estatísticas e evolução!  
Acesse online: [matheus-caffiend.netlify.app](https://matheus-caffiend.netlify.app)

---

## ✨ Funcionalidades

- **Cadastro e login** com Firebase Auth
- **Adicione cafés e bebidas energéticas** facilmente
- **Cálculo automático do nível de cafeína** no sangue (meia-vida de 5h)
- **Histórico completo** de consumo, com datas, tipos e valores
- **Estatísticas visuais**: média diária, custo total, cafés favoritos, etc.
- **Design moderno e responsivo** (dark mode incluso)
- **Modal de autenticação** elegante e intuitivo

## 🚀 Como rodar localmente

1. **Clone o repositório:**
   ```sh
   git clone https://github.com/MatheusFael/caffiend.git
   cd caffiend

   npm install


VITE_FIREBASE_APIKEY=...
VITE_FIREBASE_AUTHDOMAIN=...
VITE_FIREBASE_PROJECTID=...
VITE_FIREBASE_STORAGEBUCKET=...
VITE_FIREBASE_MESSAGINGSENDERID=...
VITE_FIREBASE_APPID=...
```

4. **Inicie o servidor de desenvolvimento:**
    ```sh
    npm run dev
    ```

O app estará disponível em `http://localhost:5173`.
